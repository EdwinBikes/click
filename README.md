# Click — Tu mundo, a un click

Primera versión visual de tienda online estática para desplegar en Vercel y evolucionar después hacia una tienda con inventario real y, más adelante, un marketplace.

## Archivos
- `index.html`: página principal y metadatos SEO iniciales.
- `style.css`: identidad visual responsive.
- `app.js`: catálogo demostrativo, filtros, búsqueda, favoritos, ficha de producto y carrito local.
- `click-mark.svg`: símbolo de marca.

## Despliegue en Vercel
Importa el repositorio `EdwinBikes/click`. No requiere comando de instalación ni build; usa la raíz del repositorio como directorio de salida. Conecta un dominio propio cuando esté verificada su disponibilidad.

## Antes de vender
Los productos, precios y reseñas son ilustrativos, no representan inventario ni opiniones verificadas. El carrito funciona solo en el navegador y no crea pedidos ni procesa pagos. No anunciar pagos, envíos ni garantías hasta configurar y probar esos servicios.

## Siguientes mejoras
1. Reemplazar catálogo de ejemplo por productos reales y fotografías autorizadas.
2. Añadir stock, variantes, SKU, disponibilidad y condiciones de entrega.
3. Crear páginas de contacto, privacidad, tratamiento de datos, cambios/devoluciones y términos.
4. Integrar una pasarela colombiana con flujo seguro en servidor y validación de notificaciones.
5. Configurar sitemap.xml, robots.txt, Search Console y dominio.
6. Preparar el modelo de datos para vendedores, comisiones y permisos antes de habilitar el marketplace.
